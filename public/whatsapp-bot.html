Meta webhook setup

Set your Meta webhook callback URL to /api/whatsapp/webhook on your public VSBIL domain. Use the same application webhook verification token configured in your server environment and subscribe to the messages field.

VSBIL validates Meta's webhook signature, identifies the correct Phone Number ID, checks the owner's subscription and only then sends the configured reply.
