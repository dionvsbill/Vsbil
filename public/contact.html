HELP & SUPPORT

Contact & Support

Use the appropriate support route so account, payment, safety and privacy requests can be handled efficiently.

Account support

For login problems, email verification, profile issues, account restrictions or connected-account questions, use the support form available inside your account or the support route provided by VSBIL.

Payment support

For activation-payment issues, include the transaction reference shown by VSBIL or the payment provider. Never include a card PIN, password or one-time authentication code in a support request.

Withdrawal support

For a withdrawal question, provide the withdrawal reference and describe the issue. Do not submit sensitive payment credentials in free-text messages.

Safety and abuse reports

Report suspicious campaigns, impersonation, scams, harassment, account takeover attempts, fake proof or attempts to manipulate rewards. Include the campaign or account reference when available and explain what happened.

Privacy requests

For access, correction, deletion, data or Google/YouTube privacy requests, use the privacy support route. We may need to verify account ownership before releasing or changing information.

Security vulnerability reports

Security researchers should use the responsible-disclosure instructions in Security & Responsible Disclosure. Do not test vulnerabilities by accessing or altering another user's information.

Response expectations

Support response times can vary based on request volume, complexity, provider dependencies and security requirements. Financial disputes and security incidents may require additional verification.
